# Security

Acclorite is a non-executing discovery and guidance tool, but security issues can still matter—especially around command rendering, filesystem handling, package metadata parsing, installation, or anything that could violate the project's local/offline guarantees.

Please avoid publishing exploit details in a public issue. Prefer GitHub's private **Report a vulnerability / Security advisory** flow when it is available for the repository. If that flow is unavailable, open a minimal public issue asking the maintainer for a private contact channel without including sensitive reproduction details.

When reporting a problem, include the affected Acclorite version/commit, distribution, relevant build options, and the smallest safe reproduction you can provide.
